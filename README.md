# QA Extension POC

QA(Quality Assurance) 확장 프로그램의 개념 증명(Proof of Concept) 프로젝트입니다.

## 📋 개요

이 프로젝트는 QA 프로세스를 자동화하고 효율화하기 위한 확장 프로그램의 프로토타입입니다.

## 🚀 시작하기

### 사전 요구사항

- Node.js (v18 이상)
- npm 또는 yarn

### 설치

```bash
# 의존성 설치
npm install
```

### 실행

```bash
# 개발 모드 실행
npm run dev
```

## 🛠 기술 스택

- **프레임워크**: (예: React, Vue, etc.)
- **언어**: TypeScript
- **테스트**: (예: Jest, Vitest, etc.)
